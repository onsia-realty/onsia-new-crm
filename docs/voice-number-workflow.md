# 음성파일 → 휴대폰번호 변환·등록 워크플로우

직원이 음성으로 읽은 휴대폰 번호 목록을 CRM에 등록하기 위한 표준 절차입니다.
두 가지 입력 경로(① 클로바노트 자동 전사, ② 수기 작성 템플릿)를 모두 지원합니다.

---

## 📌 핵심 변환 규칙

| 항목 | 규칙 |
|------|------|
| 번호 단위 | **8자리** (휴대폰 뒤 8자리). 앞에 `010` 자동 부착 → `010-XXXX-XXXX` |
| 예시 | `9046-1717` → `010-9046-1717`, `7446-5470` → `010-7446-5470` |
| 이름 | `미정` (음성에는 이름 정보가 없음) |
| 날짜 | `YY-MM-DD` 형식 (예: `26-06-07`) |
| 메모 | 아파트/지역명 — **1회 작성하면 전체 번호에 동일 적용** (예: `안산`, `용인`, `OO아파트`) |

> ⚠️ 변환 전 항상 **검수**가 필요합니다. 음성 인식·받아쓰기 특성상 숫자 1개만 빠지거나 더해져도
> 그 지점 이후 번호가 전부 밀려 틀어집니다.

---

## 경로 ① 클로바노트 자동 전사 (TXT)

직원이 음성을 녹음 → 클로바노트로 전사하면 띄어쓰기·노이즈가 섞인 **연속 숫자 스트림**이 나옵니다.

```
예) 9 0 4 6 1 7 1 7 7 4 4 6 5 4 7 0 ... 하나 4 9 9 8 1 2 1 0
```

### 변환 절차
1. 텍스트에서 **숫자만** 추출 (순서 유지). 한글 `하나` → `1` 치환, `10`·`07` 처럼 묶여 적힌
   토큰도 그대로 자릿수대로 이어붙임.
2. 추출한 숫자열을 **앞에서부터 8자리씩** 끊는다.
3. 각 8자리 앞에 `010`을 붙여 `010-XXXX-XXXX` 완성.
4. **검증**: 총 자릿수가 **8의 배수**여야 정상. 안 맞으면 누락/추가가 있으니 원본 음성과 대조.

> 정상 예: 200자리 = 25개 번호로 딱 떨어짐.

## 경로 ② 수기 작성 템플릿 (권장)

클로바 전사가 부정확할 수 있어, 직원이 음성을 직접 들으며 8자리만 받아쓰는 방식입니다.

### 1. 템플릿 생성
```bash
python scripts/build_voice_template.py
# → 음성번호_수기작성_템플릿.xlsx 생성
```

### 2. 직원 작성
| 셀 | 입력 내용 |
|----|-----------|
| `B3` | 날짜 (예: `26-06-07`) — 1회 |
| `B4` | 메모 = 아파트/지역 (예: `안산 OO아파트`) — 1회, 전체 동일 적용 |
| `A8` 이하 | 번호 8자리, 한 줄에 하나 (예: `7892-0012`) |

- 노란색 칸이 입력란입니다. `010`은 적지 않아도 됩니다 (자동 부착).
- A8의 예시 `7892-0012`는 지우고 작성.

### 3. 변환
```bash
python scripts/convert_voice_template.py "음성번호_수기작성_템플릿.xlsx"
# → 콘솔에 변환 목록 출력 + 음성번호_변환결과.xlsx 생성
#    (컬럼: 전화번호 | 이름(미정) | 메모 | 날짜)
```
- 8자리 → `010` 부착, 11자리는 그대로, 파일 내 중복 자동 제거.

## 등록 (공개DB)

변환 결과를 검수한 뒤 공개DB로 등록합니다. 등록 로직은 기존 공개DB 임포트 패턴과 동일합니다.

- 전화번호 정규화: `lib/utils/phone.ts`의 `normalizePhone` (8자리 → `010` 부착)
- 중복 체크: DB 기존 번호 대조 후 신규만 INSERT
- 현장(Site) 카테고리: `Site` 테이블 upsert + `lib/constants/sites.ts`의 `SITES` 상수에 현장명 추가
  (※ 상수에 추가해야 "집중 현장" 드롭다운에 노출됨)

참고 임포트 스크립트: `scripts/import-fabian-public.ts` (민간임대 3억대 등록 사례)

## 관련 파일

| 파일 | 역할 |
|------|------|
| `scripts/build_voice_template.py` | 수기 작성용 엑셀 템플릿 생성 |
| `scripts/convert_voice_template.py` | 작성본 → 휴대폰번호 변환 |
| `lib/utils/phone.ts` | 전화번호 정규화 공통 유틸 |
| `lib/constants/sites.ts` | 현장 카테고리 상수 (드롭다운 노출용) |
| `scripts/import-fabian-public.ts` | 공개DB 대량 등록 참고 스크립트 |

> 🔒 음성파일(`.aac`)과 추출된 번호 TXT/엑셀은 **개인정보**이므로 Git에 커밋하지 않습니다.
